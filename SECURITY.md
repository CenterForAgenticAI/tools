# Security policy

## Supported versions

We support the latest published version of each package.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/CenterForAgenticAI/tools/security/advisories/new) to report a security vulnerability privately. Never report it in a public issue or pull request.

Include:

- The package name and version, and your Pi version (`pi --version`).
- What the vulnerability allows someone to do and who could be affected.
- Steps to reproduce it, with a small example if possible.
- Any relevant logs, with tokens, passwords, and other private information removed.

A maintainer will acknowledge your report within 5 working days.
