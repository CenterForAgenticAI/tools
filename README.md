# Center for Agentic AI tools

This repository contains public releases of tools maintained by the Center for AI Research. Each package is exported into `packages/<name>/` from its canonical release source. Export commits have a fresh history and do not include development or infrastructure files.

Packages are also available from npm under the `@centerforagenticai` scope. Git tags use the form `<name>@vX.Y.Z`.

## Feedback

Issues are welcome. Pull requests are not accepted because this repository is a one-way release mirror.
